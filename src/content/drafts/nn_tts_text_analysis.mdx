As the name suggests, TTS transforms text to speech or waveforms. This, however, would not be possible without first processing the text. 

Text contains information or features that help the Vocoder generate the correct sounds, tone, pitch, etc. 

Text analyses consist of 3 main components:
1. **Text processing**: this step consists of normalizing texts from documents (e.g., defining acronyms, transforming numbers into text form), linguistic analyses.
2. **Phonetic analyses**: this part takes the normalized and processed text as input and converts it to phonetic symbols (e.g., dog to `/dôg, dŏg/`).
3. **Prosodic analyses**: From the output of the previous step (phonetic analyses), this component analyses the prosodic features of the text (e.g., pitch, duration, loudness).

## 1. Text Processing
The main function of this component is to extract, simplify, normalize, and analyze text to enable the following components (phonetic analyses and prosodic analyses) to work. 

Text processing has 3 subcomponents: **document structure detection**, **text normalization**,  and **linguistic analysis**. 

### 1.1. Document Structure Detection
In most cases, the usual input of TTS systems are not single sentences, but documents (e.g., book, guide, dialog).
