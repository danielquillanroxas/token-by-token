# Introduction

In late 2024, the MCP has taken the internet by storm and quickly gained popularity inside the AI space. But what is it really and what was the hype all about?

### Core Idea

MCP stands for Model Context Protocol, that's all it is, a protocol similar to REST when calling APIs. In the age of AI, having methods to call external APIs from your LLM application can be tedious work since all other external services may have different API Schemas and in order to use them all, you'll need to build custom integration code or adapters for each service. MCP handles this issue and provides a standardized way of providing additional "context" or calling tools to all LLM applications.
